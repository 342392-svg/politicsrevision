POLITICA - AQA Politics Evidence Atlas

Open index.html in a browser. For GitHub Pages, upload index.html to the root of your repository and enable Settings > Pages > Deploy from a branch > main > /(root).

The site includes 116 case studies across AQA Papers 1, 2, 3 and extension reading. The site works offline and saves mastery locally in your browser.

The five optional ideologies are included; only one is assessed as your chosen option.
